# 问题排查

[返回项目首页](../README.md)

先区分配置、规格、接口、模拟器和结果校验。保留失败记录，不用修改输入后的成功结果覆盖原记录。

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 网页打不开 | 服务窗口、端口、浏览器所在电脑 | 在工作站启动并访问相同端口 |
| No Python或环境失效 | 虚拟环境是否跨电脑复制 | 保留原环境，在工作站重新安装 |
| AI失败 | 实际.env及接口信息 | 核对配置，不公开凭据 |
| 无法选型 | 只有名称或缺必要参数 | 补充转化率、平衡或动力学条件 |
| 单位错误 | 拼写及表压/绝压 | 使用支持单位与明确压力基准 |
| 组分需确认 | 名称歧义、基础案例组分 | 明确异构体及映射 |
| not_probed | 报告路径及内容 | 按安装指南重新探测 |
| 执行器未就绪 | 基础案例路径及存在性 | 核对HYSYS_BASE_CASE_PATH |
| 转化率未达标 | 进出口、反应集、基准及系数 | 读取案例副本，查看诊断 |
| 超时 | 未知变量、设备状态、热规格、回退 | 定位原因，不只延长超时 |
| 衡算失败 | 顺序、流量基准、计量及负值 | 核对原始读回与案例 |
| 历史可读但新任务失败 | 许可证、COM会话及配置 | 将历史与新计算分别验证 |

## 零转化率

核对反应集、基准、系数、有效进料及实际反应进度。分离器回退可能造成透传，设备绿色状态不能单独证明反应发生。

代码在进料有效后尝试控制设置，必要时匹配明确控件辅助。出现HYSYS ACTION时按提示处理当前案例的Design / Parameters，保留操作记录。不能删除转化率或衡算检查来取得“成功”。

诊断工具见[案例读回](conversion-readback.md)。

## 诊断材料

保留同一任务下的run.json、events.jsonl、solver-diagnostics.json、case-readback.json及已有案例；验收目录另有acceptance.json。文件取决于失败阶段。

不要提供实际.env、RDP配置、访问令牌、密码或未经检查的业务数据。
