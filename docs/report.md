# AI HYSYS 反应器建模系统：技术报告

日期：2026-10-26。当前交付版本：deadline-bridge。证据包括源代码、本地测试、用户提供的远程验收截图与案例读回数据。

## 目标与技术选型

系统接受自然语言反应描述，提取组分、计量、温压、流量和转化率等规格，解释反应器选择，并在Aspen HYSYS V15内构建和求解案例。采用Windows工作站本地部署：FastAPI与静态中文网页负责交互，Pydantic校验规格，确定性规则负责模型判断，专用STA线程串行执行COM。语言模型只抽取输入，不生成模拟产物数值。RDP承担用户访问，不跨网络调用COM。

## 建模方法

甲苯歧化采用Conversion：10000 kg/h甲苯、380℃、2500 kPa绝压、总转化率50%。总计量式不能确定三种二甲苯比例，因此要求用户提供选择性或确认等选择性。本例确认各1/3、绝热及零压降后，生成三条并行反应，每条16.6667%的甲苯转化率。模型结果由HYSYS读取，再独立检查质量及元素守恒。

甲烷蒸汽重整采用Equilibrium，包含重整与水煤气变换两条可逆反应。进料甲烷1000 kmol/h、水2700 kmol/h，摩尔比1:2.7，520℃、1350 kPa绝压；对比600℃、710℃出口温度。流量、8000 h/年、零压降与HYSYS可用热力学数据作为显式确认条件，两个工况保存独立案例。

通用执行使用规格中的反应和基准组分，不按标题返回固定结果。已准备水煤气变换、逆变换及二氧化碳甲烷化额外输入，等待远程验收。当前真实执行范围为Conversion与Equilibrium；Gibbs、CSTR、PFR只有选择规则，不能宣称已支持其自动求解。

## 探索、故障与修复

既有实机记录显示，V15空案例物性状态提交与SimulationCases.Open存在限制，因此以无场景结果的基础案例副本配合文件Moniker打开。每次任务保留输入、规格、选择理由、事件、JSON/CSV与HYSYS案例，失败时尝试保存部分案例。

AI输出存在格式波动：重复“二甲苯”总称、kPa absolute单位和把kg/h填作流量基准。系统增加了有条件的异构体展开、单位归一化和基准检查；不明确的组分、冲突单位及未确认假设在入队前阻断。

零转化率故障通过实际读回定位：进出口甲苯均108.5295542 kmol/h，反应系数与组分顺序正确。用户在HYSYS中取消分离器回退选项后，读回甲苯出口54.2647771 kmol/h，达到50%转化；苯27.1323886、三种二甲苯各9.0441295 kmol/h。该手工核对样本质量相对误差约0.00152%，元素误差接近浮点精度。

COM开关在构建早期写入后仍读回true。交付版本延迟到进料就绪后重设，必要时用精确窗口和控件匹配进行UI桥接；定位失败明确提示人工操作。实际转化率与独立衡算是成功依据，不能以绿色OK或分离器透传作为反应成功。涉及人工关注的运行在报告中标注。
