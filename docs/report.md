# AI 化工反应器建模系统技术报告

日期：2026-10-26

本系统面向反应工程建模，将自然语言工艺需求转化为可审查、可执行、可追溯的 Aspen HYSYS V15 模拟任务。已完成甲苯歧化、甲烷蒸汽重整及三类额外反应的实机自然语言验收，支持结构化结果、物流表及原生案例交付。项目由本人独立设计、开发与验证，AI 编程工具用于辅助实现与分析。

## 一 技术选型与系统架构

采用 Windows 工作站本地部署，以 Python、FastAPI 和中文网页构建交互与执行服务。Python 便于集成 HYSYS Automation/COM 接口，FastAPI 提供统一的规格、工作流及运行接口，Pydantic 实现输入类型与结构约束。部署在模拟器所在工作站，减少跨主机 COM、许可证与文件路径的不确定性。

系统按职责划分为语言解析、领域规则、任务调度、模拟器适配及结果管理五层。执行链路为自然语言输入、规格提取、工程校验、假设确认、模型构建、HYSYS 求解、独立衡算及结果导出。语言模型只提取与解释输入，数值输出由 HYSYS 计算；模型选择采用可审查的确定性规则。

COM 操作在专用 STA 工作线程中串行执行。任务使用基础案例副本，按运行编号关联原始需求、规格、模型决策、事件、结果及案例。该设计兼顾模拟器状态管理和结果复核，避免多任务共享会话造成状态交叉。实际配置、密钥及运行数据与源码分开管理。

## 二 反应器选择与建模方法

甲苯歧化采用 Conversion。已知进料 10000 kg/h、380℃、2.5 MPa 及甲苯转化率 50%，任务目标是给定工艺指标下的出口分布，无需引入未提供的动力学。计量式 2C7H8 → C6H6 + C8H10 不唯一确定异构体比例；确认邻、间、对各占 1/3、绝热与零压降后，设置三条同等级并行反应，每条入口甲苯转化率 16.6667%。该方法不用于预测转化率的热力学可达性。

甲烷蒸汽重整采用 Equilibrium。主反应 CH4 + H2O <=> CO + 3H2 与变换反应 CO + H2O <=> CO2 + H2 均明确且可逆，在确认 HYSYS 平衡数据可用的前提下求解。进料 CH4 1000 kmol/h、H2O 2700 kmol/h，520℃、13.5 bar；分别计算出口 600℃及 710℃。不同工况独立保存，用于比较实际组成与热需求。

物性方法采用 Peng-Robinson，保持案例的一致计算基准。转化率、相态、动力学完整性及平衡数据可用性共同约束模型选择；不能仅依据反应名称决定模型。异构体分配、热边界、压降及年运行时间等未由需求唯一确定的条件，作为显式假设审查。

## 三 工程实现与质量控制

输入与模型一致性：通过组分映射、单位归一化、流量基准及反应计量校验，将语言输出约束为可执行规格。对歧义组分、缺失参数或未确认假设返回阻断项，避免由语言模型擅自补齐关键工程条件。

模拟器集成：采用含数据库组分及物性环境的基础案例副本，通过文件 Moniker 建立案例会话，再配置设备、物流、反应与热规格。该路径适配工作站接口约束，同时保留每次任务的独立案例；基础案例不含预置场景结果。

结果质量控制：检查变量有效性与稳定性，对给定转化率校核实际进出口变化，并独立计算质量和元素守恒，默认相对容差 0.5%。对模拟器分离器回退、控制写入及未初始化变量保留诊断，必要时提示辅助操作。设备显示正常不能单独作为反应发生或结果正确的依据。

## 四 测试与实机验证

| 验证对象 | 模型及主要条件 | 验证结果 |
|---|---|---|
| 甲苯歧化 | Conversion，甲苯转化率 50% | 实机求解与文件下载通过 |
| 甲烷蒸汽重整 | Equilibrium，600℃与 710℃ | 两工况及文件下载通过 |
| 水煤气变换 | Conversion，CO 转化率 30% | 实机求解与文件下载通过 |
| 逆水煤气变换 | Conversion，CO2 转化率 20% | 实机求解与文件下载通过 |
| 二氧化碳甲烷化 | Conversion，CO2 转化率 10% | 实机求解与文件下载通过 |

软件验证包含 234 项非 HYSYS 测试，覆盖解析、规格、选择规则、单位、执行契约及结果校验；浏览器回归与实机验收分别进行。工作站验收记录确认上述案例通过真实 AI 解析、建模、求解及 JSON/CSV/HYSYS 下载。结果与案例关联保存，组成、流量和热负荷以对应任务文件及模拟器读回为准。

## 五 适用范围与开发协作

当前真实执行范围为 Conversion 与 Equilibrium；三类额外反应验证给定转化率条件下的通用执行能力。Gibbs、CSTR、PFR 已具选择规则，自动建模与求解仍待扩展。当前求解接受条件基于有效读回、稳定性、目标转化率及衡算，工程复核仍应结合 HYSYS 原生设备状态、物性适用性与假设。

AI 编程助手用于辅助代码实现、接口分析、测试设计与诊断；模型适用性、参数假设和验收结果由本人审查确认。开发对话与运行记录作为过程附件，Git 提交记录用于追踪入库后的修改。后续重点扩展反应器及组分覆盖，完善求解状态映射，并开展更广工况范围的交叉验证。
