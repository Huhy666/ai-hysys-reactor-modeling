# AI 化工反应器建模系统技术报告

日期：2026-10-26

本项目实现自然语言需求解析、反应器选择、Aspen HYSYS V15 建模求解与结果返回的闭环。甲苯歧化、甲烷蒸汽重整两个必测场景及三个额外反应已通过远程自然语言 API 验收，结果与案例文件下载通过。系统以实际 HYSYS 计算和独立衡算作为成功依据。

## 一 技术选型与系统架构

系统采用 Windows 工作站本地部署。FastAPI 与中文网页提供输入和结果展示，Pydantic 定义严格规格，确定性规则判断模型适用性。语言模型负责提取组分、计量、温压、流量、转化率与工况，不生成模拟结果；缺失信息和新增假设须经确认后才能执行。

执行链路为：自然语言输入 → AI 结构化抽取 → 规格校验与模型选择 → 假设确认 → 串行 STA 工作线程 → HYSYS COM 建模与求解 → 数据读回及衡算 → 历史记录与文件导出。选择 Python 可直接衔接 COM 与数据校验；采用 STA 串行执行可减少线程及多案例状态冲突。

每个任务操作基础案例的副本，保存原始请求、规格、选择理由、事件、结果 JSON、物流 CSV 与 HYSYS 案例。基础案例只提供组分数据库和 Peng-Robinson 物性环境，不预置场景设备或计算结果。配置、凭据、案例与运行数据不提交到源码仓库。

## 二 反应器选择与建模方法

甲苯歧化：进料 10000 kg/h、380℃、2.5 MPa，已知总转化率 50%，无动力学要求，选择 Conversion。计量式 2C7H8 → C6H6 + C8H10 不能唯一确定异构体比例；确认邻、间、对等选择性及绝热、零压降后，配置三条同等级并行反应，每条消耗入口甲苯的 16.6667%。该比例是输入假设，不是热力学预测。

甲烷蒸汽重整：明确给出重整及水煤气变换两条可逆反应，采用 Equilibrium，并要求确认使用 HYSYS 可用热力学平衡数据。进料 CH4 1000 kmol/h、H2O 2700 kmol/h，520℃、13.5 bar；比较出口 600℃与 710℃，压降均为零，分别保存案例。8000 h/年作为年处理量换算假设，不作为求解参数。

## 三 探索过程与关键问题处理

案例创建路径：实机探索发现，空案例物性提交及 SimulationCases.Open 路径受限，改为复制无场景结果的基础案例，通过文件 Moniker 打开副本，再构建、求解与保存。

AI 格式波动：针对重复的“二甲苯”总称、kPa absolute 单位及将 kg/h 填入 flow_basis 的问题，增加有条件的异构体展开、单位归一化与流量基准校验；含糊组分及未确认假设在入队前阻断。

零转化率定位：实际读回发现甲苯进出口均为 108.5295542 kmol/h，虽有反应配置却未反应。经界面取消分离器回退并重新求解，出口降至 54.2647771 kmol/h。代码随后将控制设置延后至进料就绪，必要时匹配明确窗口与控件进行界面操作；定位失败提示人工处理并记录。成功判断仍要求实际转化率和衡算通过。

## 五 支持边界与 AI 协作

当前真实执行支持 Conversion 与 Equilibrium；三个额外反应证明给定转化率条件下的通用执行路径。Gibbs、CSTR、PFR 仅具选择规则，尚未实现自动求解。系统依赖有效许可证、基础案例和交互式 Windows 会话；界面辅助仍受窗口状态影响。两个必测场景的演示录屏已完成；重启演练与现场未知输入仍需独立验证。

AI 编程助手参与方案拆解、代码编写、测试、打包与故障分析；通过“实机反馈—诊断读回—修复—重新验收”迭代。开发对话及截图作为协作记录附件；Git 历史从源码整理入库开始，不替代完整开发记录。后续优先扩展反应器执行能力与组分覆盖，并提高界面辅助的稳定性。
