## 启动

在HYSYS远程工作站的原项目文件夹地址栏输入cmd，执行：

```cmd
.venv\Scripts\python.exe scripts\run_server.py
```

保持窗口运行，在远程浏览器打开 http://127.0.0.1:8000 。有start_web.cmd时也可双击；已有服务不必重复启动。

GitHub托管代码与文档，网页在工作站执行。GitHub Pages不能调用工作站COM和许可证，不是本项目的实机部署方式。

## 展示顺序

| 环节 | 页面操作 | 讲解重点 |
|---|---|---|
| 输入 | 完整需求或示例按钮 | 输入是工艺条件，结果不是预置数值 |
| 审查 | 选择理由、阻断项及规格 | 单位、组分、计量、工况和假设 |
| 确认 | 阅读后确认假设 | 异构体比例须有依据或显式确认 |
| 执行 | 连接、构建、求解、读取 | 实际调用HYSYS；如实展示辅助操作 |
| 核验 | 来源、组成、热负荷和衡算 | 依据数据解释，不只看成功提示 |
| 交付 | JSON、CSV和.hsc下载 | 在HYSYS打开对应案例核对 |
| 历史 | 打开已完成任务 | 需求、规格、结果和文件对应 |

“解析并生成规格”调用完整工作流，资料足够时可能自动入队。“确认全部假设”会将规格假设标记为确认，并继续校验与尝试运行，点击前阅读全部内容。

## 甲苯歧化

点击“填入：甲苯歧化”，再解析。不能只填反应名称：还需要流量、温压、转化率及异构体选择性。

核对10000 kg/h、380℃、2500 kPa绝压、总转化率50%。确认等异构体选择性、绝热与零压降；其他阻断项须补充。编辑JSON时保持正确类型与单位。

说明选择Conversion的依据：无完整动力学、明确给定转化率，目标为该指标下的出口分布。等选择性不是平衡预测。

下载conversion.hsc后：

1. Flowsheet展示反应器与进出口。
2. 双击反应器 → Reactions → Details，展示三条计量式及Toluene基准。
3. Conversion %展示各16.6667%，Results展示实际转化率和反应进度。
4. Worksheet → Conditions / Composition，展示温压、流量、组成与单位。

## 蒸汽重整

点击“填入：甲烷蒸汽重整”。核对CH4 1000 kmol/h、H2O 2700 kmol/h、进料520℃、13.5 bar，比较出口600℃及710℃。

说明Equilibrium前提：反应方程明确、反应可逆、平衡数据可用。分别打开两个equilibrium案例，展示实际组成差异。不同工况热负荷独立解释，不能把汇总值当成单一工况值。

## 新反应

可输入以下需求验证给定转化率的通用建模：

> 使用Peng-Robinson模拟CO+H2O→CO2+H2，CO基准转化率30%，不研究动力学。进料300 kmol/h，CO摩尔分数1/3、水2/3，300℃、1000 kPa绝压。包含产物CO2和H2。必要时提出运行假设，等待确认。

先核对组分是否在基础案例中，审查后再执行。

## 现场处理

- 只有名称导致信息不足：补充完整条件或点击示例。
- AI未配置或请求失败：核对实际.env，不录制凭据。
- HYSYS not_probed：重新探测，健康页不是实时探测。
- 历史可读但新任务失败：另查许可证、基础案例及执行器。
- 端口占用：优先使用已有服务，或同步修改配置和浏览器端口。
- 任务失败：保存事件和诊断，不能将旧成功任务描述为新任务成功。

录屏后检查画面、单位和两个温度工况是否完整，并备份录像。
