# 演示脚本

1. 在 RDP 工作站确认 HYSYS V15 已登录且许可证可用。
2. 双击start_web.cmd启动网页，打开 `/api/health`，展示 AI 配置与已保存的HYSYS探针状态；状态页不是一次新的实机探测。
3. 在首页填入“甲苯歧化”示例。
4. 解析并审查温度、压力、流量、物性方法、转化率和组分。
5. 展示二甲苯选择性阻断；确认等比例假设后再允许创建运行。
6. 真实 COM 构建器完成后，展示新 HYSYS 案例、收敛状态和结果来源。
7. 下载 `.hsc` 和结果文件，打开案例核对物流与反应器。
8. 填入“甲烷蒸汽重整”示例。
9. 审查 1000/2700 kmol/h 进料与 600℃、710℃ 两个工况。
10. 展示两个独立案例的组成、甲烷转化率、H2/CO 和热负荷对比。
11. 打开运行历史，证明原始请求、规格、决策、事件和案例一一对应。

两个必测场景的远程自然语言API验收已由用户截图确认通过；网页演示仍应从输入开始重新执行。额外通用性用run_generalization.cmd验证。界面桥接或人工操作应完整出现在录屏中。禁止展示Fake数据作为HYSYS结果。
